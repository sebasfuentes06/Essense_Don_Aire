Diseña un sistema UI/UX completo, moderno, premium y elegante para una plataforma web y móvil de venta de lociones llamada “Essence Don Aire”.

El diseño debe sentirse luxury, premium, minimalista, elegante y sofisticado, inspirado en marcas de perfumes de alta gama. Debe transmitir exclusividad, confianza, limpieza visual y experiencia premium.

Crear un Design System completo y pantallas responsive (Desktop + Mobile).

OBJETIVO DEL PROYECTO:
La plataforma debe gestionar un negocio de lociones y perfumes con control administrativo, vendedores y clientes finales. Incluir dashboard, inventario, catálogo, pedidos, ventas, pagos, clientes, proveedores, promociones y sistema móvil.

PALETA DE COLORES:

MODO CLARO:
- Color principal: Dorado suave #C9A227
  Sensación premium/luxury

- Color secundario: Blanco crema #F8F5F0
  Fondo limpio y elegante

- Color tercero: Negro carbón suave #2B2B2B
  Contraste y tipografía

Uso:
- Botones principales → Dorado
- Fondo principal → Crema
- Texto → Negro suave
- Cards → Blanco con sombra suave
- Hover buttons → Dorado más oscuro
- Inputs → Bordes sutiles elegantes

MODO OSCURO:
- Color principal: Dorado elegante #D4AF37
- Fondo principal: Negro elegante #121212
- Cards: Gris humo #2E2E2E

Uso:
- Fondo → Negro elegante
- Cards → Gris humo
- CTA → Dorado elegante
- Textos → Blancos suaves
- Bordes → Gris tenue elegante
